## 🚀 Quick Start

Because this project uses pure HTML5, CSS3, and Vanilla JavaScript with zero external dependencies, you can run it in two ways:

### Option 1: Open Directly in Browser
Simply double-click `index.html` or open it in any modern browser.

### Option 2: Run a Local HTTP Server
```bash
git clone https://github.com/YOUR_USERNAME/win98.git
cd win98
python3 -m http.server 8098
```
Then open **`http://localhost:8098`** in your browser.
